# To-Do List

A simple command-line to-do list application written in Kotlin. This was one of my first programming projects as a college freshman and helped me practice loops, lists, user input, and conditional logic.

## Features

- Add tasks
- View the current task list
- Delete tasks by number
- Exit through a menu-driven interface

## Requirements

- Kotlin

## Run the program

Compile and run the Kotlin file from the project directory:

```bash
kotlinc ToDoList.kt -include-runtime -d ToDoList.jar
java -jar ToDoList.jar
```

Tasks are stored in memory while the program is running.
